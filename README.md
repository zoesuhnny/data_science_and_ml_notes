# data_science_guide
These are all of my notes I create for data science, machine learning, and deep learning.  I learn best with hands-on practice, and revisiting these notes helps me refresh and solidify my knowledge in these areas.

**llm_notes_from_hugging_face:** notes on llms, from following the LLM Course on Hugging Face's website: https://huggingface.co/learn/llm-course/chapter3/3 

**(smaller_dataset)_llm_notes_from_hugging_face:** a copy of the llm notes, but with a smaller dataset that labels poems based on their mood (4 possible labels: positive, negative, no impact, and mixed).  This transforms the text classification problem into multiclass classification specifically, instead of a binary one.  This was done because the dataset used for the actual HF LLM course was **too large for my MacBook laptop to handle,** and my RAM would max out before training finished.  The conceptual steps followed alongside the LLM course are the same.

**01_911_Calls_Data_Capstone_Project:** Essentially a data science problem set I solved using Pandas, NumPy, Matplotlib, and Seaborn.  I had to organize data and plot graphical representations based on the instructions given. In short: a project to show I know how to use these tools.
